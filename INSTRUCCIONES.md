# 🎯 Instrucciones Rápidas - Kiro Day

## ▶️ Ejecutar la Aplicación

```bash
cd quien-la-embarro
npm run dev
```

La aplicación se abrirá automáticamente en tu navegador en `http://localhost:5173`

## 🎮 Demo Rápida

1. **Abrir** la aplicación en el navegador
2. **Hacer clic** en cualquiera de los 3 incidentes de ejemplo (cards grises en la parte inferior)
3. **Presionar** el botón "🔬 Investigar Incidente"
4. **Explorar** el análisis:
   - Ver severidad estimada (badge rojo/naranja/amarillo/verde)
   - Revisar cronología visual de eventos
   - Leer hechos identificados vs hipótesis
   - Ver evidencia faltante
   - Revisar acciones correctivas y preventivas
5. **Cambiar** a la pestaña "👔 Informe Ejecutivo" para ver resumen gerencial
6. **Copiar** el informe completo con el botón "📋 Copiar Informe"

## ✍️ Probar con Texto Libre

También puedes escribir tu propio incidente tecnológico en el área de texto. El motor analizará:
- Patrones de tiempo mencionados
- Servicios y tecnologías involucradas
- Severidad según palabras clave
- Acciones correctivas realizadas
- Y más...

## 🛑 Detener la Aplicación

Presiona `Ctrl+C` en la terminal donde se ejecuta.

## 🏗️ Compilar para Producción

```bash
npm run build
```

Los archivos estarán en `dist/` listos para servir.
